# javascript-dom-storage-series

A rapid-fire, single-page vanilla JavaScript sprint for DOM updates, form handling, events, array methods, and LocalStorage. The flow is designed for a focused 2-hour coding session where each exercise builds practical instincts you can reuse immediately.

## 10-Exercise Sprint Overview

1. **Warm-Up Render & Reduce**  
   Render an array into the DOM with `forEach` and compute totals with `reduce`.
2. **Form State**  
   Capture and render form state using `submit` + `preventDefault`.
3. **LocalStorage Bridge**  
   Persist and restore form state with `localStorage` via `JSON.stringify`/`JSON.parse`.
4. **Analytics Engine (filter/map)**  
   Filter student data by grade threshold and map results to just names.
5. **Shopping Cart Logic (find)**  
   Track product quantities by finding existing cart entries with `find`.
6. **Method Chaining**  
   Combine `filter().sort()` to produce refined movie lists.
7. **Boolean Checks (some/every)**  
   Validate datasets with `every()` and detect flagged cases with `some()`.
8. **Deletion Pattern**  
   Remove items from state immutably using `filter()`.
9. **Event Delegation**  
   Handle clicks through one parent listener using `e.target` matching.
10. **Final Boss Expense Tracker**  
    Build a mini tracker using forms, rendering, `reduce()`, and persistent LocalStorage state.

## Run

Open `index.html` in any modern browser. No frameworks, bundlers, or build tools are required.
